# ساختار پروژه
- js/data.js    ← همه محتوا فارسی/انگلیسی ({f:'..',e:'..'})، رنگ‌ها، ترتیب بخش‌ها، پروژه‌ها. ۹۰٪ تغییرات فقط اینجاست.
- js/render.js  ← ساخت صفحه از data.js و زبان فعلی (نوع بخش جدید = یک تابع در B)
- js/app.js     ← موشن‌ها، نشانگر سفارشی، تم، تغییر زبان، PWA
- css/style.css ← ظاهر؛ توکن‌ها در :root
- manifest.webmanifest و sw.js ← PWA (نام/رنگ برنامه در manifest جدا ویرایش می‌شود؛ بعد از هر تغییر، V در sw.js را بالا ببرید)
- نیاز به HTTPS برای نصب PWA
