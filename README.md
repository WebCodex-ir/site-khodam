# سایت خودم

وب‌سایت شخصی در پوشهٔ `webcodex.ir` قرار دارد. مخزن GitHub محل اصلی نگهداری کد است؛ آن را از هر دستگاهی می‌توان دریافت و تغییرات را با push منتشر کرد.

## انتشار نسخه

هر بار که تغییرات به شاخهٔ `main` ارسال شود، GitHub Actions شمارهٔ وصله را در فایل `VERSION` افزایش می‌دهد، یک تگ نسخه می‌سازد و یک GitHub Release منتشر می‌کند.

برای دریافت آخرین تغییرات و ارسال ویرایش‌ها:

```bash
git pull
git add .
git commit -m "توضیح تغییر"
git push
```

هر push به شاخهٔ `main` نسخهٔ وصله را افزایش می‌دهد و یک GitHub Release می‌سازد. نسخهٔ فعلی در `VERSION` نگهداری می‌شود.

سایت را می‌توان مستقیم از پوشهٔ `webcodex.ir` با هر وب‌سرور ایستا اجرا کرد. برای کار ابری از هر دستگاهی می‌توان از GitHub Codespaces استفاده کرد؛ دسترسی آن به موجودی حساب GitHub وابسته است.
